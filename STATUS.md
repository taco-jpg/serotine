# SIP Statuses

Statuses describe where an idea actually is. They are not achievements.

## Idea

The proposal is early, incomplete, or mostly exploratory.

## Draft

The proposal is coherent enough for useful discussion.

## Review

The proposal is being seriously evaluated, prototyped, or prepared for implementation.

## Accepted

The project intends to implement or adopt the proposal, although details may still change.

## Final

The SIP describes stable behavior that Serotine actually uses.

## Deferred

The idea may be good, but it is not currently a priority.

## Rejected

The project intentionally decided not to pursue this direction. The document can remain as useful historical context.

## Withdrawn

The author no longer wants to pursue the proposal.

## Superseded

Another SIP replaced this one. Link to the replacement.

## Status changes

Statuses can move backward when reality changes. An Accepted proposal can return to Draft. A Final SIP can be superseded.

Do not preserve an inaccurate status just because it looks cleaner in history.
